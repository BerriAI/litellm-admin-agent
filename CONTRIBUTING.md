# Contributing

- Use, modify and redistribute the project under the [MIT License](LICENSE).
- Open an [issue](https://github.com/BerriAI/litellm-admin-agent/issues) for a bug or feature request. Include the gateway version, deployment method and steps to reproduce the problem. Remove credentials and private data from logs.
- To propose code changes, fork the repository, create a branch in your fork and open a pull request against `main`.
- Describe the problem, your change and how you tested it. Follow the [development guide](docs/development.md) to run the tests and container checks.
- Keep gateway addresses, Slack tokens, API keys, encryption keys and local `.env` files out of commits. Use fake values in tests.
- Follow the [security reporting instructions](SECURITY.md) for vulnerabilities.

Maintainers review and merge pull requests. A public repository lets you read, clone, fork and propose changes. You need write access from a repository administrator to push branches directly; public access and the MIT License do not grant that permission.
