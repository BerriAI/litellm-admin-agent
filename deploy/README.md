# Deployment

Start with the [self-hosted setup guide](../README.md). The supported templates are the root `Dockerfile`, `compose.yaml`, and `render.yaml`.

`gateway-sso.Dockerfile` and `gateway-sso-build.json` record the historical BerriAI sandbox OAuth overlay. They are internal deployment provenance, depend on private infrastructure, and are not required or recommended for a new installation. For hosted SSO requirements and the portable personal-key alternative, see [gateway compatibility](../docs/compatibility.md).
